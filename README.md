# arylide
আমাদের গল্পটা একটা বাড়িকে নিয়ে না, একটা আশিয়ানাকে নিয়ে।প্রতিটা মানুষের জীবনে একটা স্বপ্ন থাকে - নিজের একটা ঠিকানা। যেখানে সকালটা শুরু হবে আলো দিয়ে, বিকালটা কাটবে ছাদে বসে। যেখানে মা রান্নাঘরে হাসবে, বাবা বারান্দায় চা খাবে।Arylide Ashiyana আমরা বানাই নাই, আমরা বানাইতেছি একটা অনুভূতি। যেখানে প্রতিটা ফ্লোর, প্রতিটা জানালা, প্রতিটা বারান্দা বলব
